# Residency Workshop Program: Learning → Instrument → Community Value → Federated Blueprint
**Draft v0.1 — 2026-11-02**

## Program principle
Every class should produce: (1) an authentic improvement or measurement, (2) at least one reproducible knowledge artifact, (3) a demonstrable skill, (4) a joyful in-world interaction, (5) a maintainable handoff, and (6) an optional contribution to a portable skill portfolio. No graded labor surveillance.

## Education path ladders
### Path A — Grower and Field Naturalist
Observe crops & wildlife -> assign bed IDs and take repeat photos -> identify plants cautiously -> harvest + loss logs -> seed germination counts -> soil sampling and pH method -> controlled plot trials -> interpretation with uncertainty -> teach a new observer.
### Path B — Reclaimed Electronics Apprentice
Electrical safety and multimeter -> salvage identification -> breadboard LED/switch -> ESP32 firmware -> analog sensor -> calibration experiment -> battery/power budget -> enclosure -> local gateway -> field deployment -> repair -> teach.
### Path C — Community Data Scientist
Units/tare and dates -> spreadsheet/logs -> missingness and sampling bias -> plot data -> photo annotation -> classifier confidence and false positives -> time-series seasonal charts -> experimental design -> compare plots across communities -> publish replicable analysis.
### Path D — Site Systems Steward
Inventory -> building maintenance -> compost, irrigation and solar inspections -> permits and safe oversight -> resource flow mapping -> work parties -> communication -> governance and privacy -> coordinate resilient shared infrastructure.
### Path E — Knowledge Weaver and Mentor
Document build -> accessibility documentation -> test lesson with peers -> mentor verified practical skill -> archive design -> adapt design to another community -> federation workshop -> maintain living curricula.
### Path F — AI Familiar Keeper
Task decomposition -> data provenance -> draft proposals -> opt-in outreach policies -> agent capability gates -> simulations -> event-triggered workflows -> adversarial input tests -> transparent run log -> operate and audit community familiar.

Sessions can be parallelized by different facilitators; learners choose tracks. For each workshop publish prerequisites, accessible alternatives, salvage BOM, purchased safety/precision components, measured outputs, lesson assessment, mentor rubric, site steward and device maintenance owner.

## Sample quest ladder: soil moisture
1. **Soil Detective**: observe damp/dry garden sections (10 discovery XP).
2. **Meter Maker**: assemble low-voltage probe with mentor (50 creation XP).
3. **Calibration Keeper**: compare probes with gravimetric or trusted reference measurements (35 practice XP).
4. **Signal Shepherd**: transmit timestamped readings to local gateway, intentionally disconnect, recover no duplicate data (35 practice XP).
5. **Garden Analyst**: distinguish stale probes, rainfall response and genuine plant needs (30 research XP).
6. **Repair Mentor**: teach someone else to service station (40 mentorship XP).
7. **Blueprint Carrier**: another site builds it independently and shares results (75 federation XP per consenting participant).
XP are proposed playtest values, not mandatory course assessment.

## Program feedback to game
Workshop enrollment appears as in-world events, but mere attendance does not certify proficiency. Practical evidence generates skill claims requiring mentor verification. Functioning artifacts become spatial map objects and maintenance tasks. Every device logs provenance, calibration and responsible stewards. The familiar helps schedule and match; cannot directly assign people work. Build cards become portable community knowledge assets.

## Evaluation
Pre/post skill demonstration, ability to repair without instructor, actual data completeness, peer confidence, sensor reliability, maintenance time, social participation, user joy and ability to opt out. Track aggregate results more than individual productivity.
